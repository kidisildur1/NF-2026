# Поздравление для Николая

Это статический сайт — сервер, сборка и зависимости не нужны.

1. Создайте новый репозиторий на GitHub.
2. Распакуйте архив в корень репозитория и загрузите все его файлы.
3. В настройках репозитория откройте **Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
5. Сохраните настройки. Через несколько минут GitHub покажет ссылку на сайт.

Главная страница — `index.html`; кнопка на ней ведёт к последовательности фактов в `facts.html`.
